# Politique de confidentialité — Instant Pause

Page publique : **https://ajanedouby.github.io/instant-pause-privacy/**

Ce dépôt ne sert qu'à héberger la politique de confidentialité de l'application Android
**Instant Pause** (`com.instantpause.app`), exigée par Google Play. Elle est générée depuis
`PRIVACY_POLICY.md` du dépôt de l'application.

- `index.html` — la page publiée (autonome, sans ressource externe, clair et sombre, en anglais, espagnol puis français)
- `PRIVACY_POLICY.md` — la même politique en Markdown, dans le même ordre de langues
- `.nojekyll` — désactive le traitement Jekyll

L'application ne collecte aucune donnée : pas d'accès réseau, pas de compte, pas de SDK tiers.
